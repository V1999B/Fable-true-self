the language

There is no such thing as a syntax error here. Every string is a program, every program is a creature, and the address bar always holds the one you're looking at.

f g
step forward drawing a line / step forward without drawing
+ -
turn by the current angle (30° to begin with)
2…9
set the angle to a full turn divided by that digit
( )
narrow / widen the angle a little
< >
shrink / grow the step
[ ]
remember where you are / go back there
*
the whole program again, from here. at the bottom of the recursion it is just f
|
swap left and right
o
one more copy of everything, arranged around the seed
c
shift the colour
~
sway

So f[+<*][-<*] is a tree, because a tree is a line with two smaller trees on it. 6*+*--*+* is Koch's curve. The rest are named as they turn up: the genus from the body plan (brackets, stars, symmetry), the epithet from how the thing came out.

Dimension is measured, not looked up: the creature is laid on grids of finer and finer boxes, and the rate at which it fills them is the number. A line scores 1, a solid 2. It is a rough ruler held against a finite drawing, so Koch reads about 1.2 where the ideal curve is 1.26.

Drift lets the garden choose for itself. It keeps a memory of every shape it has passed through and follows the child that looks least like any of them.
